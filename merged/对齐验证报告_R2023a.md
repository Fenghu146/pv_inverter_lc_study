## 5. R2023a 与 R2024b/R2026b 的差异记录（复现经验）

1. **R2023a 是三者中兼容性最好的**：SPS 离散模式原生支持，R2026b 的四个坑
   （Solver Configuration/代数环/初始化/悬空节点）全部不存在。
2. R2023a 打不开 R2024b 保存的 .slx（模型向下不兼容）→ 必须 `build_models` 重建
   （对方模型是脚本生成的，重建无损）。
3. `run_l3` 等入口假设基础工作区变量已由 build_models 的 setvars 预置 → 批处理前
   需先执行 `project_params` 的变量初始化（见上文脚本）。
4. 本机 R2023a 初始安装缺 SPS/Control Toolbox/Simscape Electrical，需通过
   "Add Products" 补装（许可证池已含，无需重新购买）。

## 6. 复现命令（学校机器照抄）

```matlab
% 前置：一次性的模型重建（约 2 分钟）
cd <对方仓库>\PV_LC_project
addpath('control')
make_cfg_const
build_models

% 每次批处理前的工作区初始化
p = project_params();
V = struct('Vdc_val',p.Vdc,'Cdc_val',p.Cdc,'Ron_sw',p.Ron_sw, ...
  'L_val',p.L,'Rf_val',p.Rf,'Rg_val',p.Rg,'Lg_val',p.Lg,'C_val',p.C, ...
  'Rd_val',p.Rd,'Ug_pk',sqrt(2)*p.Ug_rms,'fg_val',p.fg,'Im_val',p.Im_rated, ...
  'Im_data',[0 p.Im_rated;4 p.Im_rated],'G_data',[0 1000;4 1000], ...
  'T_data',[0 25;4 25],'V0_pv',p.pv_V0,'V0_val',p.mppt.V0,'Bias_i_val',0);
fn = fieldnames(V); for i=1:numel(fn), assignin('base',fn{i},V.(fn{i})); end

% 实验
T = run_l3('core');          % L3 基线六工况
run_combo('hardfix')         % 推荐方案组合工况
run_l4('all')                % MPPT
verify_all                   % L0-L5 全量
```
