# R2023b（学校版本）复现与兼容指南

学校机房为 MATLAB/Simulink **R2023b**。本指南说明哪些东西能直接用、哪些已做兼容、
如何在学校机器上复现两边的实验。**核心结论：merged/ 合并版与全部 DPS/C 代码不受
影响；对方开关层实验在 2023b 上按 A 路径重建即可（可行性已验证）。**

## 1. 版本兼容矩阵

| 内容 | 2023b 可用性 | 说明 |
|---|---|---|
| `merged/` 合并版（A0–A4 全部数据/图） | ✅ 直接用 | 纯 Python（numpy/scipy/matplotlib），不依赖 MATLAB |
| `dsp/` C2000 固件 + 单元测试 | ✅ 直接用 | gcc/TI 编译器，与 MATLAB 无关 |
| `matlab/pv_inverter_L_LC_R2023b.slx` | ✅ 已导出 | 本机 R2026b `exportToVersion` 生成（45 KB） |
| `matlab/PV_LC_models_R2023b/`（28 个） | ⚠️ 已导出，开关桥降级 | 对方 28 个模型批量导出（1.6 MB）；**Simscape Electrical 块官方不支持降级导出**，桥臂块转换仅部分成功，须在 2023b 里打开核验 |
| `matlab/pv_inverter_L_LC.slx`（R2026b 原版） | ❌ 打不开 | Simulink 模型向下不兼容 |
| 对方原版 28 个 .slx（R2024b 保存） | ❌ 打不开 | 同上 |

> 本机 R2026b 实测：对对方模型执行 exportToVersion 会明确警告
> "Export to previous version does not support Simscape-based blocks from
> Simscape Electrical" 并以"部分成功"落盘——因此导出件只作**参考**，**正式
> 复现请走第 2 节的重建路径**。

## 2. 路径 A（推荐）：在 2023b 上重建对方的模型再跑实验

**可行性依据（已核查）**：
- 对方 28 个模型全部由 `build_models.m` 程序化生成，块清单仅含
  `powerlib`（Specialized Power Systems：Universal Bridge / 电源 / 测量 / RLC）与
  `simulink` 基础块，**无任何 R2024b 专属块或函数**；
- powergui 配置为 **Discrete 模式 + FixedStepDiscrete**（0.5 µs），R2023b 的 SPS
  离散求解器原生支持——我们在 R2026b 上撞到的 4 个坑（Simscape Solver
  Configuration、代数环、t=0 初始化、悬空节点）全部是 R2026b 将 SPS 迁移到
  Simscape 底层所致，**2023b 上不存在**；
- 控制/测试代码只用了 `persistent` 等老语法。

**在学校机器上的步骤**（需要 Simulink + Specialized Power Systems 许可）：

```matlab
% 0) 把对方的仓库拷到本机（含 control/ models/ tests/ 等）
cd <对方仓库根>\PV_LC_project
addpath('control'); addpath('tests');

% 1) 可选：先跑不依赖 Simulink 的解析层自检（需 Control System Toolbox）
test_L0            % 纯解析，任何版本都过

% 2) 用 2023b 重建 28 个模型（覆盖 R2024b 原件前先备份 models/）
make_cfg_const
build_models       % 重建全部 PV_grid_*.slx

% 3) 核心开关层实验（每工况 0.4 s 仿真、0.5 us 步长）
T = run_l3('core')            % 6 工况，~3 s/工况
T = run_l3('lscan')           % L 值扫描
run_step('core')              % 峰值阶跃动态
run_resonance                 % 15 工况线性网络（需 Control System Toolbox）
run_combo                     % 基线组合 6 工况
run_combo('hardfix')          % 推荐方案（峰谷采样+饱和补偿）
run_l4('all')                 % MPPT：稳态/远起点/温度阶跃
verify_all                    % L0-L5 全量（输出 607 项）

% 4) 对照基准：results/*.csv 的 git 版本（对方 R2024b 运行结果）
%    THD/TDD/Idc 应在小数点后 1-2 位内一致；sign(iL) 零交叉的
%    网格敏感度可造成 <0.5 pp 的 THD 差异，属正常。
```

**检查点**：`run_l3('core')` 跑完后的验收值（来自对方报告 4.2 节）——
L 70/130/200 W THD ≈ 1.77/1.34/1.05%，LC ≈ 2.56/1.51/1.03%；
`run_combo('hardfix')` 六工况 THD 全部 <5%、Idc ≈ −18…−20 mA。

## 3. 路径 B：我们的 Simulink 框架（演示用途）

`matlab/pv_inverter_L_LC_R2023b.slx` 可在 2023b 直接打开。注意它的定位是
R2026b 框架的降级导出（ee_lib Simscape 块），**参数计算以 merged/ 与 dsp/ 为准**，
模型仅作结构展示；若要在 2023b 实跑对照，请按 `matlab/build_simulink_model.m`
的注释在 2023b 中重建连线。

## 4. 下载 R2023b 的两种方式（需 MathWorks 账号授权）

1. **官方安装包**：mathworks.com/downloads 选 R2023b（约 20 GB，支持 Windows/
   Linux），登录有有效许可证的账号下载安装即可；
2. **学校镜像/正版客户端**：多数高校通过校园正版化平台分发，安装时勾选
   Simulink + Specialized Power Systems（Simscape Electrical 若有也一并勾选）。

工具箱需求：Specialized Power Systems（必需）、Control System Toolbox
（仅 `test_L1/L2/run_resonance` 需要）、Simscape Electrical（仅打开/跑
Simscape 版桥臂需要，SPS 离散模式不需要）。

## 5. 合并版与学校实验的关系

merged/ 的 A0–A4 数据与 `run_tasks.py` 不需要 MATLAB，可直接在学校任何电脑
上运行：`python merged/run_tasks.py`（约 12 分钟）。学校 2023b 机器跑路径 A
得到开关层数据后，与 merged/ 的平均层数据对照，即完成"平均模型 vs 开关模型"
的两级交叉验证（对应对方报告的 L2/L5 ↔ L3 层级关系）。
