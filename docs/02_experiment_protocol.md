# 实验协议与数据规范

> 出处：对应原方案实验方案与数据记录要求。本文执行已定稿的 E1–E10 对比矩阵、公平性规则和测量口径。
>
> 适用对象：PV（75 V / 2.7 A，200 W）→ 单相 H 桥 → L 或 LC 耦合网络 → PCC（36 V / 50 Hz 交流源 / 隔离变压器侧）。
>
> 固定参数：`f_sw = 20 kHz`（单极性倍频 SPWM，纹波 40 kHz），`L = 0.5 mH`，`C = 20 µF`，`R_d = 0 / 1 / 2.2 Ω`，`L_g = 0.5 mH`，`C_dc = 4.5 mF`，死区 400 ns。目标控制器为 TI C2000（F28379D）。

## 1. 测量与计算口径

1. **THD** 按 2–50 次谐波计算，遵循 GB/T 与 IEEE 1547 口径。分析窗口为 200 ms，即 10 个工频周期，频率分辨率为 5 Hz。
2. **THD 不包含 40 kHz 开关纹波。** 高频纹波单独报告，包含：
   - `i_g` 经高通（> 5 kHz）后的峰峰值；
   - FFT 中 40 kHz（`2f_sw`）分量幅值及其占基波的百分比。
3. L 与 LC 默认使用完全相同的 DSP 程序和控制参数。只有 LC 出现明显谐振时，才允许调整 `R_d` 或电流环 `Kp`，并必须在当次记录和最终报告中注明。
4. 除耦合网络及其已注明的谐振处理外，输入功率、交流条件、功率级、测量点位和示波器设置保持一致。
5. 原始记录只追加、不覆盖、不修改。所有导出、筛选和计算均在原始文件副本上完成。

## 2. 对比实验矩阵

功率点 35% / 65% / 90% 分别约为 70 W / 130 W / 180 W。稳态点 E1–E6 每个工况重复 3 次并取均值。

| 编号 | 结构 | 工况 | 主要记录 | 采集要求 |
| --- | --- | --- | --- | --- |
| E1 | L | 35%（约 70 W）稳态 | `i_g`、`i_L`、`u_g` 波形，THD，40 kHz 纹波，`P_pv`、`P_ac` | 重复 3 次，取均值 |
| E2 | L | 65%（约 130 W）稳态 | 同 E1 | 重复 3 次，取均值 |
| E3 | L | 90%（约 180 W）稳态 | 同 E1 | 重复 3 次，取均值 |
| E4 | LC（`R_d` 最终值） | 35%（约 70 W）稳态 | E1 的全部项目，另加 `i_C` | 重复 3 次，取均值 |
| E5 | LC（`R_d` 最终值） | 65%（约 130 W）稳态 | E1 的全部项目，另加 `i_C` | 重复 3 次，取均值 |
| E6 | LC（`R_d` 最终值） | 90%（约 180 W）稳态 | E1 的全部项目，另加 `i_C` | 重复 3 次，取均值 |
| E7 | LC | 65%（约 130 W），`R_d = 0` 与最终值对比 | 谐振现象、`i_C` 频谱、振荡波形 | 保存振荡波形 |
| E8 | L 与 LC | 35% → 90% 辐照阶跃 | 电流过渡过程、超调、调节时间 | 示波器单次触发 |
| E9 | L 与 LC | 启动并网过程 | 冲击电流、振荡 | 示波器单次触发 |
| E10 | L 与 LC | MPPT 稳态 | `P_pv` 波动、`η_MPPT` | 稳态记录，按第 4 节命名保存 |

E1–E3 与 E4–E6 按相同功率点配对比较。E7 的两种 `R_d` 结果都必须保留，不得只保留最终值。E8、E9 使用单次触发，不把多次触发拼接成一次过渡过程。

## 3. 公平性控制清单

每次实验开始前逐项勾选。任一项未确认时，不开始该次记录。

| 序号 | 核对项 | 要求 | 勾选 |
| --- | --- | --- | --- |
| 1 | 同一 DSP 程序与参数 | 程序版本、编译产物和控制参数一致；谐振调整已另行注明 | ☐ |
| 2 | 同一功率级 | H 桥、直流母线和交流条件不变 | ☐ |
| 3 | 同一 L 器件 | 两种结构使用同一个 `L = 0.5 mH` 器件 | ☐ |
| 4 | 同一功率点 | 对照实验使用同一 35%、65% 或 90% 功率点 | ☐ |
| 5 | 同一测量点位 | 探头与电流钳位置不变，引出线长度符合第 5 节 | ☐ |
| 6 | 同一示波器设置 | 存储深度、采样率、时基和触发设置不变 | ☐ |
| 7 | `R_d` 状态记录 | 明确记录 0、1、2.2 Ω 或当次最终值 | ☐ |
| 8 | 重复次数 | E1–E6 完成 3 次；E8、E9 按单次触发保存 | ☐ |

允许的唯一未预先固定差异是 LC 明显谐振时的 `R_d` 或电流环 `Kp`。调整前保存原参数结果，调整后在文件名备注和实验记录中写明原值、新值和原因。

## 4. 数据命名与原始数据

文件名格式：

```text
E{编号}_{L|LC}_{功率点}_{重复次数}_{日期}.csv
```

示例：`E2_L_65_2_20261020.csv` 表示 E2、L 结构、65% 功率点、第 2 次重复、2026-10-20 的原始 CSV。

- 编号使用 E1–E10，结构只使用 `L` 或 `LC`。
- 功率点使用 `35`、`65`、`90`；E9 无稳态功率点时使用协议规定的工况标识，并在备注中说明。
- 重复次数从 1 连续编号。E8、E9 的单次触发记为 1，不补造重复次数。
- 日期使用 `YYYYMMDD`。
- 原始 CSV 生成后设为只读。发现错误时保留原文件，另存修正版并在备注指向原文件，不直接修改原始数据。

## 5. 示波器与测量点位

| 项目 | 要求 |
| --- | --- |
| 存储深度 | ≥ 1 Mpts |
| 采样率 | ≥ 5 MS/s |
| 单次捕获长度 | 200 ms |
| 稳态谐波窗口 | 200 ms，对应 10 个 50 Hz 工频周期 |
| 电流钳引出线 | 10 cm |
| 点位一致性 | L、LC 及 LC 的不同 `R_d` 状态使用相同物理位置 |

200 ms 捕获长度同时满足 THD 窗口要求。示波器时基、垂直量程、带宽限制和触发沿在同一对照组合内不得改动；量程溢出时整组对照重新采集，不单独更换某一结构的设置。
