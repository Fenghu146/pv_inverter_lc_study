> 出处：对应技术需求文档第十一章交付物逐项列表。本文仅列出已知交付物，不编造未给出或未定稿的交付物。
>
> 状态定义：软件先行阶段（当前）或硬件到位后的后续阶段。
>
> 平台：TI C2000（F28379D）；功率路径 PV（75 V / 2.7 A，200 W）→ 单相 H 桥 → L 或 LC 耦合网络 → PCC（36 V / 50 Hz 交流源 / 隔离变压器侧）。

> 已定参数：`f_sw = 20 kHz`（单极性倍频 SPWM，纹波 40 kHz），`L = 0.5 mH`，`C = 20 µF`，`R_d = 0 / 1 / 2.2 Ω`，`L_g = 0.5 mH`，`C_dc = 4.5 mF`，死区 400 ns。
>
> 已定口径：THD 按 2–50 次谐波计算，窗口 200 ms，频率分辨率 5 Hz；THD 不包含 40 kHz 开关纹波，另设高通纹波峰峰值和 40 kHz 分量占基波百分比。
