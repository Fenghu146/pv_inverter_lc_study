## 4. 换算规则（`python/params_canonical.py`，json → 引擎键名）

| 引擎键 | 工程来源 | 换算 | 工程口径值 |
|---|---|---|---|
| `P_rated / Ug_rms / fg / fsw` | rating、switching | 直接取 | 200 / 36 / 50 / 20000 |
| `P_points` | `power_points[].P_W_approx` | 列表抽取 | [70, 130, 180] |
| `G_points` | `power_points[].irradiance` | ×1000 | [350, 650, 900] |
| `Vdc` | `rating.V_mpp_V` | 直接取 | 75 |
| `L / C / Cdc` | `plant` | 直接取 | 5e-4 / 2e-5 / 4.5e-3 |
| `Rf` | `plant.R_parasitic_ohm` | 直接取 | 0.1 |
| `Rd` | `plant.R_d_default_ohm` | 直接取 | 0 |
| `Lg` | `plant.L_g_H` | 直接取 | 5e-4 |
| `Rg` | json 未规定 | 取与对方一致 | 0.1 |
| `Td` | `switching.t_dead_ns` | ×1e-9 | 400e-9 |
| `td_norm` | — | `2·Td/(1/fsw)` | 0.016（ΔV=1.2 V @75 V，与 `DT_COMP_COEF`×Vdc 一致） |
| `i_sat_L / i_sat_LC` | 按工程口径重算 | `Δi_pp/2 = Vdc/(8·L·fsw)/2` | 0.46875 A |
| `Kp_pr` | `control.current_pr_kp` | **/ V_mpp**（视作 V/A → 占空比/A） | 0.0627 |
| `Kr_pr` | `control.current_pr_kr` | / V_mpp | 4.0 |
| `f_bw_pr` | `control.current_pr_wc_rad_s` | /2π | 0.7958 |
| `vmax_pr` | `control.modulation_limit` | 直接取 | 0.95 |
| `pll_Kp / pll_Ki` | `control.pll_pi_kp / ki` | 直接取 | 0.67 / 22 |
| `pll_wint_max` | `protection.f_g_range_Hz` | `2π·10` | 62.83 |
| `mppt_Kp / mppt_Ki` | `control.voltage_pi_kp / ki` | 直接取 | 0.2 / 5 |
| `mppt_dV / mppt_Tp` | `control.mppt_dV_V / mppt_T_ms` | /1000 | 0.5 / 0.1 |
| `mppt_Vmin / mppt_Vmax` | `control.Vdc_ref_limit_V` | 直接取 | 62 / 75 |
| `mppt_Im_max` | `control.I_amp_limit_A[1]` | 直接取 | 10 |
| `mppt_V0` | `mppt_init_frac_Voc` | ×Voc | 72 |
| `pv` | 对方标定（**未标定到工程口径**） | 原样，标记 `pv_uncalibrated=True` | — |
| `nsub / ctrl_delay_beats` | 引擎需要 | 10 / 1.5 | — |

**已知近似（必须写进报告）**：
1. 引擎的 PLL 是对方 T/4 延时结构，工程口径是 SOGI；A5 只能借 SOGI 的标称 Kp/Ki，**PLL 动态不等价**。
2. PR 的 Kp/Kr 换算把 DSP 系数视作"V/A"，与 DSP 内部标定可能差一个 ADC 缩放；A5 的电流环带宽因此是**上界估计**。
3. PV 单二极管模型尚未标定到 Voc 90 V / Isc 2.9 A / Vmpp 75 V / Impp 2.67 A（`pv_uncalibrated`）；A5 的 `fixed_i` 静态对比不依赖 PV 模型，**但 A5 不做 MPPT 结论**（MPPT 仍以 A4 为准，属交叉验证口径）。

## 5. 机器交叉校验（`python/check_params.py`）

真源 = `params/params.json`；六段校验：

1. **json 自洽**：f₀、f_res（含 L_g 0.5/0.1 mH）、f_s/6、`design_range == [10·f_g, f_sw/10]`、`TBPRD == EPWMCLK/(2·f_sw)`、`Z0 == √(L/C)`、`power_points ≈ irradiance×P_n`、`I_mpp ≈ P_n/V_mpp`、`ΔV == 2·Td/Ts·Vdc == 1.2 V`。
2. **`dsp/include/param.h`**：宏求值（剥 `f/u` 后缀、递归展开、`eval`）后与 json 逐项比 33 项。
3. **`params_canonical.py`**：与 json 换算结果逐项比 28 项。
4. **`params_merged.py`**：共享项（`P_rated / Ug_rms / fg / fsw`）必须一致。
5. **差异白名单** `WHITELIST_DIFF`：登记并说明 Vdc、Cdc、L、C、Rd、Lg、Rf、Td、td_norm、Kp_pr、Kr_pr、f_bw_pr、pll_Kp、mppt_dV、mppt_Vmax、mppt_Kp、i_sat、pv、P_points、G_points、R_d 档位——**未登记的差异即 FAIL**。
6. **docs 冻结文本**：`docs/01`、`docs/02` 的已定口径行须与 json 一致（注意 `R_d = 0 / 1 / 2.2 Ω` 带空格写法），并检查本文件（docs/12）存在。

**本机实测（2026-11-02）**：`cd python && PYTHONUTF8=1 python -u check_params.py` → **PASS 98 / FAIL 0 / WARN 0 / INFO 21**（json 自洽 12 项 + `param.h` 33 项 + `params_canonical` 28 项 + merged 共享项 4 项 + docs 冻结口径 15 项 + 本文件 6 项），明细见 `results/tables/params_check.csv`；退出码 1 当且仅当 FAIL>0。

### 6.4 结论（工程口径）

1. **L 结构三个功率点全部稳定**；死区补偿是 THD 主导项（70 W：4.843 % → sign 0.430 %），与交叉验证口径（docs/07 结论②）方向一致。
2. **LC 在 R_d = 0 时三个功率点全部发散**（THD 95–379 %、HF 372–722 %）。因此 `params.json` / `param_design.py` 的「f_res（2252 Hz）< f_s/6（3333 Hz）⇒ 自然阻尼、R_d 可先取 0 Ω」判据，在 0.5 mH / 20 µF 组合与本文 §4 近似换算的 PR 增益下**不成立**——该判据只解析了被动的 LCL 网络，未计入闭环近似下的增益与延时。
3. **加 R_d 即稳定**：1.0 Ω 与 2.2 Ω 在 130 W / 180 W 均稳定（THD 0.58–0.80 %、HF 0.20–0.32 %、Idc 微安级）；2.2 Ω 的 HF 更低，THD 与 1.0 Ω 基本持平。
4. **工程动作**：LC 模块**必须装 R_d，仿真起点取 1.0 Ω**（与《实现方案》4.2 第二档一致），最终值由 E7 实验确定；BOM 第 9 项已由"可选"改"必装"（docs/14 §6）。
5. **口径对照**：A2（交叉验证口径 2 mH / 12 µF，R_d = 1 Ω）LC 稳定且 THD ≈ 0.71–0.89 %；A5（工程口径 0.5 mH / 20 µF，R_d = 1 Ω）≈ 0.80 %。量级与方向一致——"LC 对低次谐波未必更好"在两套口径下都成立；引用数字时必须写明口径。
6. **局限**：A5 用 `fixed_i` 静态对比（不启用 PV / MPPT，见 §4 与 §7），控制律取 §4 的近似换算；因此本节的结论限于"耦合网络 + 死区补偿"的静态对比，不含 MPPT 动态。
