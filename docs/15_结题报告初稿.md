## 一、项目概述与研究问题

本项目在**同一台低压小功率单相光伏并网逆变器**上，仅更换交流侧耦合网络（L 与 LC），在相同功率、相同开关频率、相同交流侧条件下对比并网性能（技术需求见 [docs/06](06_技术需求逐项验收.md) 所引《技术文件2.docx》）。

- **结构 A（L）**：PV → 单相 H 桥 → L → PCC。
- **结构 B（LC）**：同一结构，在交流侧节点并联 C（可串小阻尼电阻 R_d）。
- **平台**：TI C2000（F28379D）、100–300 W 单相 H 桥、PV 侧 200 W / 75 V MPP、PCC 侧 36 V / 50 Hz 隔离交流源（[docs/03](03_deliverables.md) 第 7–11 行、[docs/01](01_implementation_plan.md) 第 7–9 行）。
- **四个必答结论**：① LC 的高频开关纹波抑制是否更好；② 不同功率点的 THD 差异；③ LC 是否引入谐振/振荡；④ 复杂度、器件数量与调试难度的差异（[docs/06](06_技术需求逐项验收.md) 第七章）。
- **明确不做**：LCL 及高阶滤波器、MPC/神经网络/强化学习、220 V 市电直并、极限 THD/效率（[docs/06](06_技术需求逐项验收.md) 第十二章）。

项目分 12 个月、两个阶段推进：软件先行阶段（前 2–3 个月，阶段 1–5）已完成；硬件联调与实验阶段（阶段 6，E1–E10）待硬件到位（[docs/01](01_implementation_plan.md) 第 23–35 行）。

## 二、技术路线与两结构公平对比原则

对比成立的前提是"只变耦合网络"。公平性控制清单共 8 项，每次实验前逐项确认（[docs/02](02_experiment_protocol.md) 第 3 节）：

| 序号 | 核对项 | 要求 |
| --- | --- | --- |
| 1 | 同一 DSP 程序与参数 | 程序版本、编译产物、控制参数一致；谐振调整另行注明 |
| 2 | 同一功率级 | H 桥、直流母线、交流条件不变 |
| 3 | 同一 L 器件 | 两结构使用同一只 0.5 mH 电感 |
| 4 | 同一功率点 | 对照实验使用同一 35%、65% 或 90% 功率点 |
| 5 | 同一测量点位 | 探头与电流钳位置不变，引出线 10 cm |
| 6 | 同一示波器设置 | 存储深度、采样率、时基、触发不变 |
| 7 | R_d 状态记录 | 明确记录 0/1/2.2 Ω 或当次最终值 |
| 8 | 重复次数 | E1–E6 各 3 次；E8、E9 单次触发 |

**唯一允许的未预先固定差异**：LC 出现明显谐振时调整 R_d 或电流环 Kp，且必须保存调整前结果、在文件名与报告中写明原值/新值/原因（[docs/01](01_implementation_plan.md) 第 21 行、[docs/02](02_experiment_protocol.md) 第 53 行）。

## 三、工程底座完成情况（软件先行阶段）

### 3.1 DSP 算法层与 C 单元测试

`dsp/` 为 11 个头文件 + 11 个 C 源文件 + `tests/test_control.c`（593 行）的 C99 算法层，HAL 分 PC stub 与 F28379D driverlib 两层（[docs/05](05_acceptance_report.md) 第 20 行）。本机实测：

```bash
cd dsp
gcc -std=c99 -O2 -I include tests/test_control.c src/*.c -o tests/test_control.exe
./tests/test_control.exe     # SUMMARY PASS (0 failed)
```

覆盖 SOGI-PLL 锁相、准 PR 电流环、P&O MPPT、保护状态机、调制映射与死区补偿、预充路径（[docs/05](05_acceptance_report.md) 第 46 行：35 PASS / 0 FAIL；[docs/11](11_技术文件校验与复跑验证报告_2026-11-01.md) §2.1 重编后 SUMMARY PASS）。在 C2000Ware 26.01 下完整构建 **0 error**，产出 `pv_inverter.out` 164 KB 与 `pv_inverter.hex` 54 KB；**尚未上板**，PWM 波形、400 ns 死区、ADC 零偏、CMPSS 阈值仅通过编译层验证（[docs/05](05_acceptance_report.md) 第 107 行）。

### 3.2 参数设计与解析层

`python/design/param_design.py` 读 `params.json`，输出 L 扫描、LC 谐振、R_d 判据与衰减预估（[results/tables/param_design.txt](../results/tables/param_design.txt)）。关键实测值见 §4.2。

### 3.3 平均模型仿真 A0–A5

- `python -u python/run_tasks.py`：A0 解析层、A1 L 扫描、A2 核心对比、A3 动态阶跃、A4 MPPT，**交叉验证口径**（[README](../README.md) 第 30 行）。
- `python -u python/run_canonical.py`：A5 工程口径核心对比，输出 `A5_analytic.csv`、`A5_core.csv`、`A5_rd_sweep.csv` 与 `A5_thd_comp.png`（[python/run_canonical.py](../python/run_canonical.py) 第 14–15 行）。**2026-11-02 已跑完：22 例共 842 s，四件产物全部落盘**，[docs/12](12_参数口径与单一真源.md) §6 已回填完整结果表。
- **A5 结论（工程口径）**：L 结构三功率点全部稳定（无补偿 THD 4.843 / 2.734 / 2.019 %，sign 档降至 0.430 / 0.443 / 0.474 %）；**LC 在 R_d = 0 时三个功率点全部发散**（THD 95–379 %、高频占比 372–722 %、幅值偏差最大 −68.8 %）；**R_d ≥ 1 Ω 即稳定**（1.0 Ω：130 W 0.801 %、180 W 0.583 %；2.2 Ω：0.780 %、0.585 %，高频更低）。故 LC 模块必装 R_d、仿真起点取 1.0 Ω，最终值由 E7 实验确定（[docs/12](12_参数口径与单一真源.md) §6.4）。
- 已知近似（必须随结论一并引用）：A5 借用 SOGI 标称 Kp/Ki，但引擎 PLL 为 T/4 延时结构，**动态不等价**；PR 系数换算视作 V/A，电流环带宽为**上界估计**；PV 单二极管模型尚未标定到工程口径（`pv_uncalibrated=True`），故 **A5 不出 MPPT 结论**（MPPT 以 A4 为准，属交叉验证口径）（[docs/12](12_参数口径与单一真源.md) §4）。

### 3.4 R2023a 开关层
