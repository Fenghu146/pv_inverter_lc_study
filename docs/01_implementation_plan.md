# 软件先行实施计划

> 出处：对应原方案阶段划分与十二个月里程碑。本文仅落实“软件先行”实施安排，不改动已定稿技术口径。
>
> 项目：基于 DSP 的光伏并网逆变器 L 与 LC 耦合结构对并网性能影响研究。
>
> 平台：低压小功率单相光伏并网逆变器。功率路径为 PV（75 V / 2.7 A，200 W）→ 单相 H 桥 → 耦合网络（L 或 LC）→ PCC（36 V / 50 Hz 交流源 / 隔离变压器侧）。
>
> 已定参数：`f_sw = 20 kHz`（单极性倍频 SPWM，纹波 40 kHz），`L = 0.5 mH`，`C = 20 µF`，`R_d = 0 / 1 / 2.2 Ω`，`L_g = 0.5 mH`，`C_dc = 4.5 mF`，死区 400 ns。目标平台 TI C2000（F28379D）。
>
> 当前阶段无硬件，软件先行。软件先行覆盖约十二个月周期的前 2–3 个月，为后续联调与实验 E1–E10 准备算法、仿真与数据处理工具链。

## 1. 已定技术口径

以下口径已定稿，后续计算、仿真、实验与报告均不得改动。

1. **THD**：按 2–50 次谐波计算（GB/T 与 IEEE 1547 口径），窗口 200 ms（10 个工频周期），频率分辨率 5 Hz。
2. **高频纹波**：THD 不包含 40 kHz 开关纹波。另设两项指标，并与 THD 分开报告：
   - `i_g` 高通（> 5 kHz）后的峰峰值；
   - FFT 中 40 kHz（`2f_sw`）分量幅值及其占基波的百分比。
3. **对比公平性**：L 与 LC 使用完全相同的 DSP 程序与控制参数。仅当 LC 出现明显谐振时，允许修改 `R_d` 或电流环 `Kp`，并在报告中注明。除耦合网络外，一切条件保持一致。

## 3. 阶段 0：环境与工程底座（已完成）

**目标**：建立可复现的计算、仿真与版本管理环境。

**任务**：安装并确认 Python 3.14 及 `numpy`、`scipy`、`matplotlib`、`pandas`、`control`；安装 MATLAB R2026b、Simulink 与 Simscape Electrical；建立 Git 工程。

**产出物**：可运行的 Python 科学计算环境、MATLAB/Simulink/Simscape Electrical 环境、Git 仓库。

**验收标准**：Python 可导入上述五个库；MATLAB 可调用 Simulink 与 Simscape Electrical；Git 可记录后续文档与代码版本。

**依赖**：无。本阶段已完成。

## 4. 阶段 1：参数设计与理论计算（S1–S3）

### S1：L 扫描

- **目标**：在已定 `L = 0.5 mH` 的基准上，完成 L 结构的参数扫描与理论计算，明确其对并网电流谐波和开关纹波的影响。
- **任务**：按已定开关频率、死区和交流条件计算 L 结构的电流纹波与基波阻抗；扫描只作为对照，不替换已定 `L = 0.5 mH`。
- **产出物**：L 扫描计算记录、基准 `L = 0.5 mH` 的理论结果。
- **验收标准**：计算使用本文第 1 节口径；THD 与 40 kHz 纹波指标分开给出；未引入未给定参数。
- **依赖**：阶段 0。

### S2：LC 参数与谐振

- **目标**：核算 LC 耦合参数及谐振特性。
- **任务**：使用已定 `L = 0.5 mH`、`C = 20 µF`、`R_d = 0 / 1 / 2.2 Ω` 和 `L_g = 0.5 mH` 计算谐振相关量；比较不同 `R_d` 对谐振阻尼的影响。
- **产出物**：LC 参数与谐振计算说明。
- **验收标准**：三种 `R_d` 均被记录；若后续因明显谐振改变 `R_d` 或电流环 `Kp`，说明中必须注明偏离项及原因。
- **依赖**：S1 的基准 L 结果。

### S3：稳定性判据

- **目标**：建立 L 与 LC 在相同控制参数下的稳定性判据。
- **任务**：依据已定参数比较两种耦合网络的稳定边界；仅在 LC 明显谐振时评估 `R_d` 或电流环 `Kp` 的必要调整。
- **产出物**：稳定性判据与判定记录。
- **验收标准**：默认控制参数保持一致；任何参数调整均有“明显谐振”的判定依据和报告注明。
- **依赖**：S1、S2。

## 5. 阶段 2：仿真对比（S4–S6）

### S4：三功率点稳态对比

- **目标**：在 35%、65%、90% 三个功率点比较 L 与 LC 的稳态并网性能。
- **任务**：在相同控制参数、输入功率和交流条件下仿真两种结构，分别计算 THD、高通纹波峰峰值和 40 kHz 分量。
- **产出物**：三功率点稳态对比数据与图表。
- **验收标准**：两类指标分开报告；除耦合网络外条件一致；每个对比均可追溯到同一控制参数集。
- **依赖**：S1–S3。

### S5：动态对比

- **目标**：比较两种结构在辐照变化和电网电压变化下的动态表现。
- **任务**：仿真辐照 35% → 90% → 35% 阶跃，以及电网 ±10% 阶跃；记录电流过渡过程。
- **产出物**：动态波形、超调与调节过程对比记录。
- **验收标准**：阶跃方向、幅度和其余条件在两种结构间一致；控制参数默认不变。
- **依赖**：S4 的稳态基准。

### S6：MPPT 跟踪效率与敏感性

- **目标**：评估 P&O 的 MPPT 跟踪效率及其步长、周期敏感性。
- **任务**：在相同功率级与交流条件下，对 L 与 LC 进行 P&O 步长和周期敏感性仿真，并统计 `P_pv` 波动与跟踪效率。
- **产出物**：MPPT 敏感性数据与对比结论。
- **验收标准**：步长和周期的对比组合在两种结构间一致；不把 MPPT 参数差异混入耦合结构差异。
- **依赖**：S4、S5。

## 6. 阶段 3：数据分析工具链

**目标**：对仿真与实验 CSV 使用同一处理流程，避免口径漂移。

**任务**：实现统一 CSV 处理，至少输出按 2–50 次谐波计算的 THD、`i_g` 高通（> 5 kHz）峰峰值，以及 40 kHz 分量幅值和占基波百分比。THD 窗口固定为 200 ms，频率分辨率固定为 5 Hz。

**产出物**：可重复运行的数据处理工具及输入输出说明。

**验收标准**：同一输入重复处理结果一致；THD 与高频纹波分开输出；原始 CSV 不被改写。

**依赖**：阶段 0；指标定义以本文第 1 节为准。可先用仿真数据验证，实验数据留待阶段 6。

## 7. 阶段 4：DSP 算法层

**目标**：在 PC 上完成面向 F28379D 的算法层单元测试。

**任务**：实现并测试 SOGI-PLL、PR、MPPT 与保护状态机。DSP 程序和控制参数作为 L 与 LC 的共用版本管理。

**产出物**：算法源码、PC 单元测试和共用参数记录。

**验收标准**：单元测试可重复通过；除已注明的 LC 明显谐振调整外，两种结构调用同一程序与同一参数。

**依赖**：阶段 0、S3。本阶段不依赖实机。

## 8. 阶段 5：Simulink 模型

**目标**：建立包含 L 与 LC 两种耦合结构的 Simulink 模型。

**任务**：基于 MATLAB R2026b、Simulink 与 Simscape Electrical，按已定功率级、开关频率、死区及无源参数建模；模型输出供阶段 3 工具链处理。

**产出物**：含 L 与 LC 的 Simulink 模型、仿真设置和结果导出文件。

**验收标准**：模型参数与已定值一致；两种结构可在同一控制参数下运行 S4–S6。

**依赖**：阶段 0、阶段 1。阶段 2 的对比由本模型执行，阶段 3 验收其导出数据。

## 9. 阶段 6：硬件到位后的联调与实验（E1–E10）

**目标**：在样机到位后完成 L 与 LC 的公平对比实验。

**任务**：依次执行 E1–E10。E1–E3 为 L 结构 35% / 65% / 90% 稳态；E4–E6 为 LC 结构对应功率点稳态；E7 为 LC 在 65% 下 `R_d = 0` 与最终值对比；E8 为 35% → 90% 辐照阶跃；E9 为启动并网；E10 为 MPPT 稳态。具体矩阵、重复次数和记录格式以实验协议为准。

**产出物**：原始实验 CSV、实验记录表、核心对比图和必要的示波器波形。

**验收标准**：每次实验前完成公平性核对；每点按协议重复并取均值；THD 与 40 kHz 纹波分开报告；参数偏离均已注明。

**依赖**：阶段 1–5 的程序、模型、参数和数据处理工具，以及硬件、隔离电源和测量设备。

## 10. 阶段依赖关系

```text
阶段0（已完成）
  └─ 阶段1：S1 → S2 → S3
       └─ 阶段5 Simulink模型
            └─ 阶段2：S4 → S5 → S6
                 └─ 阶段3 工具链验证
阶段4 DSP算法层（依赖阶段0与S3，可与阶段2、3、5并行）
阶段1–5全部完成且硬件到位
  └─ 阶段6：E1–E10
```

S1–S6 是软件先行阶段的计算与仿真编号；E1–E10 是硬件到位后的实验编号。二者不得混用，也不得用仿真结果替代 E1–E10 的实验数据。
