本目录包含 TI C2000 F28379D 的工程骨架。**当前状态：已用真实 C2000Ware 编译链接成功，产出 `.out` 与 `.hex`。**

## 一键下载（板子到位后）

```powershell
cd dsp\ccs
.\flash.ps1             # 构建 + 烧写 + 校验 + 复位运行
.\flash.ps1 -SkipBuild  # 只烧写现有固件
```

- 烧写走 CCS 自带 `DSLite.exe`（命令行，无需开 CCS GUI）：
  `DSLite flash --config pv_inverter_flash.ccxml -f -v -u build\pv_inverter.out`
- [pv_inverter_flash.ccxml](pv_inverter_flash.ccxml) 是 LAUNCHXL-F28379D 板载
  XDS110 + TMS320F28379D 的目标配置，由 CCS 的 DSS 生成器官方产出
  （[gen_ccxml.js](gen_ccxml.js)，`dss.bat gen_ccxml.js` 可重新生成）。
  **不要手工拼这个文件**：F28379D 带 CLA 协处理器，手写配置缺 `tixds510cla1.xml`
  驱动实例时 DSLite 报 `An invalid processor ID has been found`（已踩坑验证）。
- 烧写参数：`-f` 加载、`-v` 校验、`-u` 结束后复位运行；擦除由加载器按需自动完成。
- 板子未连接时 `identifyProbe`/`flash` 无法测试，插上 USB 后（设备管理器出现
  XDS110 类设备）直接跑 `.\flash.ps1` 即可。

## 三个必须知道的构建细节

**1. 中文路径**
工程在 `...\大创\...` 下。`cl2000` 处理命令行里的非 ASCII 路径会失败，所以
`build.ps1` 把所有源文件和 include 目录都换算成**相对 build 目录的路径**再传给它。
直接手敲绝对路径会报 `cannot open source file`。

**2. 自写链接脚本，不用 C2000Ware 那份**
`device_support\f2837xd\common\cmd\2837xD_FLASH_lnk_cpu1.cmd` 是给整套示例工程用的，
把 `.cinit` 塞进 FLASHB 且不留余量，本工程链接时直接报
`program will not fit into available memory`。本目录的
[2837xD_FLASH_lnk_cpu1.cmd](2837xD_FLASH_lnk_cpu1.cmd) 按实际布局重排：
`.text`→FLASHE、`.cinit`→FLASHC、常量→FLASHB，并显式声明 `.TI.ramfunc`
（缺它链接器会报 `section generated by __attribute__((ramfunc)) requires a SECTIONS specification`）。

**3. `--output_file=` 而不是 `-o=`**
EABI 模式下 `-o=pv_inverter.out` 会被解析成"输出扩展名 .out"，
导致 `cannot find file ".out"`。必须用 `--output_file=pv_inverter.out`。

## 上电顺序（重要）

**第一次上电必须断开功率级**，只连 LaunchPad：

1. 只给 USB 电，功率级母线不上电
2. 烧写、运行，示波器看 EPWM1A/1B、EPWM2A/2B
   - 20 kHz 互补方波，两个边沿都有 400 ns 死区
   - A 腿与 B 腿同相（EPWM1SYNCOUT 同步 EPWM2）
3. 确认 `ST_OFFSET_CAL` 期间（前 50 ms）CMPA = 0、不输出 PWM
4. 给 V_g 加 36 Vrms/50 Hz，确认 PLL 锁定、`theta` 跟随
5. 以上全对，才接功率级

**未确认死区就接功率级 = 上下管直通炸管。**

## 与算法层的关系

```
app/main.c          ← 入口，ISR 里只调 app_isr()
src/app.c           ← 编排：ADC → 算法 → 调制 → HAL
src/control_isr.c   ← 纯算法（PC 可测）
src/pwm_mod.c       ← v* → CMPA 映射（PC 可测）
src/hal_c2000.c     ← 唯一写寄存器的地方
src/hal_stub.c      ← PC 替身（单元测试用）
```

**改引脚只改 `pv_inverter.syscfg` 与 `hal_c2000.c` 的 `GPIO_*` 宏**，算法层一行都不用动。
